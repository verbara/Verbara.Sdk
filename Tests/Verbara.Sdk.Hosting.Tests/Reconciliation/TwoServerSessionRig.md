# Two-server session test rig

`TwoServerSessionRig` composes the existing `PoolSweepRig`, creates attached servers `a` and `b`, and starts no background sweep. Use it from an `IAsyncLifetime` test class and dispose it in `DisposeAsync`; cleanup checks the index invariant before disposing the host, even if the test body failed. `AmiCaptureReplay.ReplayRig` is also internal and reachable from other tests in its assembly; its existing start, replay and cleanup behavior is preserved.

Drive serial channel events directly. Register **every concurrent producer** with `Track(task)`. A scenario that defers notifications must additionally register the task for its actual notification with `AfterNotification(task)` and release its gates before cleanup. `AssertIndexesAsync` and disposal await both sets with a bound. Neither awaited drivers nor this helper promise a general outbox completion-order guarantee. A test that parks a notification owns the causal completion fence for that notification; elapsed time is never its oracle.

`CallSessionManager.InspectIndexes()` copies every entry from the four actual dictionaries: held session ids, linked ids, channel ids and raw bridge-to-session-id mappings. Invoke it only after the scenario is quiescent; the separate copies are not an atomic concurrent snapshot. The shared invariant checks each entry's held object identity and key, including raw bridge ids that resolve to no held instance. It then checks every present leg of every unended held call against the actual channel entries for its server. On the current shared index, this inspection filters entries by their owner's `ServerId`; it does not provide a public scoped lookup or repair shared-index collisions.

Historical departed rows and retained ended calls need no channel entry. Any entries they retain still must name the held instance carrying that key. An entry pointing at a released instance fails even if the test never looked up that entry's key. Corrupt copied-snapshot controls exercise that direction without mutating the engine. The rig's green retirement case reconciles one attached server with a complete table that keeps Y and removes X; it tests the historical-row allowance without asserting the future detached-call reconciliation behavior.

For admission/collision regressions, use `TwoServerSessionRig.AddChannels(server, linkedId, ids)` to send raw arrivals without assuming a call was created. `Open` requires a held call on that server and resolves it by `FindCurrentByLinkedId`, inspecting the actual index and filtering its owner; it never returns another server's call or synthesizes the missing call.
